# Sequential Thinking Skill (순차적 사고)

Use this skill when tackling complex coding, architecture, debugging, or multi-step engineering tasks.

## Core Methodology

1. **Problem Decomposition**: Break down the problem into atomic, ordered steps.
2. **Hypothesis Formation**: Formulate explicit hypotheses for root causes or architecture choices.
3. **Step-by-Step Verification**: Verify each hypothesis empirically against logs, code definitions, or test outputs before proceeding.
4. **Thought Refinement**: Continuously revise and adjust steps if unexpected evidence emerges.
5. **Synthesis**: Consolidate findings into clear, actionable conclusions.
