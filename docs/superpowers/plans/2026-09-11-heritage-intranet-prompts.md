# 주변유적 자동 받기 — 실행 프롬프트 모음

같은 폴더의 `2026-09-11-heritage-intranet-nearby-sites.md` 가 계획서다. 이 문서는 **그 계획을 실행시키는 프롬프트**다.

**사용법**
- 위에서부터 **하나씩** 붙여 넣는다. 한 프롬프트가 끝나고 **눈으로 확인한 뒤** 다음으로 간다
- **프롬프트 0(공통 머리말)을 매번 앞에 붙인다.** 새 세션에서는 특히 그렇다
- 한꺼번에 다 붙여 넣지 않는다. 여섯 종을 한 번에 시키면 사이트 화면 하나 바뀔 때 전부 멈춘다

## 프롬프트 A — 막힌 것 먼저: WebEngine 을 살린다

인트라넷 자동화는 QtWebEngine 을 쓴다. **이게 안 되면 나머지가 전부 무의미하다.** 이것부터 한다.

```
QtWebEngine 자식 프로세스가 이 PC에서 뜨지 못한다. 그래서 topographic_browser 테스트를
CMakeLists.txt 에서 DISABLED TRUE 로 빼 두었다. 단서는 apps/Qt6/bin 옆에 zlib.dll 이 없다는 것이다.

원인을 찾아 고쳐라. 추측으로 DLL을 복사해 두고 됐다고 하지 마라.
QtWebEngineProcess.exe 를 직접 실행해 무엇이 없다고 하는지 확인하고,
scripts/copy-webengine-runtime.ps1 이 이미 있으니 그것과 어긋나는지도 봐라.

끝났다고 말할 조건: CMakeLists.txt 의 DISABLED TRUE 를 지우고
ctest --preset release -R topographic_browser 가 실제로 통과할 것.
통과하지 못하면 무엇 때문인지 말하고 멈춰라.
```

## 프롬프트 E — 색과 범례

```
계획서 7.4 · 7.5 를 구현하라.

색: 자료 종류마다 색 하나. 표를 코드 한 곳에만 두고 거기서만 읽어라.
  지정유산 #8E44AD / 현상변경허용기준 #E67E22 / 매장유산유존지역 #2E86C1
  문화유적분포지도 #27AE60 / 지표조사구역 #16A085 / 발굴조사구역 #A0522D
  빨강 금지(조사구역이 쓴다), 회색 금지(수치지형도가 쓴다).
  면은 테두리만, 0.3~0.4mm. 어중간한 반투명은 피하라(LayerOps::paintsFullyOpaque 참고).

범례: 색은 종류마다 하나, 줄은 유적마다 하나.
  QgsCategorizedSymbolRenderer(유적명필드, cats) 를 걸되 색은 전부 같은 값을 준다.
  QgsRendererCategory 의 세 번째 인자가 범례 글자다.
  - src/core/LayerOps.cpp 의 applySoilCategoryStyle 을 그대로 쓰지 마라.
    그건 값마다 색을 바꾸고, 200개를 넘으면 단색으로 떨어진다.
    주변유적은 한 종류 한 색이고, 상한을 넘으면 조용히 떨어지지 말고 사용자에게 말해야 한다.
  - 유적명이 빈 레코드도 "기타" 카테고리로 받아라. 카테고리가 없으면 그 폴리곤이 아예 안 그려진다.
  - 유적명 컬럼 이름은 실제 확인한 값을 써라. 추측으로 박지 마라.

레이어창에는 종류 이름만 나와야 한다. 유적명은 도면 범례에만 나온다.
  QGIS는 레이어 하나에 범례 구현이 하나라 레이어창과 도면 범례가 같이 쓴다.
  그래서 QgsMapLayerLegend 를 상속해 안에서 갈라라. src/core/DemColorRampLegend.cpp 가 같은 틀이다.
  넘어온 node 의 최상위 루트가 m_layer->project()->layerTreeRoot() 면 레이어창이다 → 색 견본 하나만.
  아니면 도면 범례다 → QgsMapLayerLegend::defaultVectorLegend() 에 그대로 넘겨라.
  근거: LayoutService::tuneSheetLegend() 가 setSyncMode(Manual) + resetManualLayers() 로
  도면 범례에 자기 복제 트리를 준다. 이 앱의 도면 범례 경로는 전부 그 함수를 지난다.

  도면 쪽 노드를 손으로 만들지 마라. 기본 노드에 붙은 렌더러 rule key 가 있어야
  setLegendFilterByMapEnabled(true) 의 인쇄범위 걸러내기가 동작한다.
  같은 이유로 렌더러를 단색으로 바꾸지 마라.

끝났다고 말할 조건:
- LayoutService::sheetLegendLabelDump() 결과에 실제 유적명이 한 줄씩 들어 있을 것
- 한 종류의 범례 색이 여러 줄에 걸쳐 모두 같은 값일 것
- 프로젝트 트리로 QgsLayerTreeModel 을 만들면 layerLegendNodes() 가 1개일 것
- 지도 범위를 좁히면 sheetLegendLabelDump() 의 줄 수가 줄어들 것
테스트로 고정하라.
```
