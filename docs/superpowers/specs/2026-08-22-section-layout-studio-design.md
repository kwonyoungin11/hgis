# 단면도 조판 스튜디오 설계

## 목표

Bentley Descartes에서 만든 수직 단면 GeoTIFF를 ka-hgis에서 불러와, 거리·표고 눈금과
조사 정보를 갖춘 가로형 단면도를 만들고 Illustrator 후편집용 PDF로 출력한다.

## 사용자 흐름

1. 메인 도구막대의 **단면도** 아이콘을 누른다.
2. `단면도` 탭이 열리며 A3 가로 용지가 기본으로 보인다.
3. 좌측 레이어 창에서 기존 레이어를 켜거나 GeoTIFF를 추가하고 순서를 조정한다.
4. 우측 속성 창에서 축척, 좌표계 표기, 표고 보정, 눈금 간격과 기준선 스타일을 정한다.
5. **단면도 만들기**를 누르면 용지와 축이 다시 구성된다.
6. **PDF 저장**으로 사진은 고해상도 래스터, 눈금·문자·선은 벡터인 PDF를 만든다.

## 화면 구성

- 좌측: 단면 레이어 목록, 표시/숨김, 위/아래 순서, GeoTIFF 추가, 목록 갱신
- 중앙: `QgsLayoutView` 기반 가로 용지 미리보기
- 우측:
  - A3/A4 가로 용지
  - 도면명
  - 축척 `1:N`
  - 좌표계 표시
  - 표고 보정값
  - 표고 눈금 간격(기본 0.10m)
  - 거리 눈금 간격(기본 자동)
  - 붉은 점선 기준선 표시 및 굵기(기본 0.20mm)
  - 단면도 만들기, PDF 저장

## 좌표 모델

- 이 기능의 입력은 Bentley Descartes에서 평면화해 내보낸 **수직 단면 GeoTIFF**다.
- 기존 GPKG `section_line`은 평면 지도상의 단면 위치선이므로 Z 스키마로 변경하지 않는다.
- 단면 GeoTIFF의 화면 가로축은 단면 진행 방향의 거리로 취급한다.
- 화면 세로축은 표고 Z로 취급한다.
- 좌측 표고값은 `GeoTIFF Y + 표고 보정값`으로 표시한다.
- 하단 거리값은 현재 단면 범위의 왼쪽을 `0.00m`로 한 상대 누적거리로 표시한다.
- GeoTIFF가 이미 실제 표고를 가진 경우 표고 보정값은 0이다.
- 일반 지도처럼 세로축을 북ing으로 표시하지 않는다.
- 원본 3D의 벽면 수직 깊이는 이 2D 단면도에서 복원하지 않는다.

## 조판 출력

- 기본 용지는 A3 가로, 선택 사항은 A4 가로다.
- 지도 프레임은 단면 레이어 전체 범위를 유지하고 용지 안에 맞춘다.
- 좌측에는 0.10m 간격 표고선과 표고 숫자를 배치한다.
- 하단에는 자동 1-2-5 계열 또는 사용자가 지정한 간격으로 거리 눈금을 배치한다.
- 단면 기준선은 `#D7191C`, 점선, 0.20mm로 출력한다.
- 도면명, 축척, 수평 좌표계, 수직 기준(표고 m), 작성일을 벡터 문자로 넣는다.
- `QgsLayoutExporter`에서 300 DPI와 강제 벡터 출력을 사용한다.

## 코드 구조

- `src/core/SectionLayoutService.*`
  - 눈금 계산과 검증
  - `QgsLayoutItemMap`으로 단면 GeoTIFF 본체 렌더링
  - `QgsLayoutItemPolyline`/`QgsLayoutItemLabel`로 축, 기준선, 표제 정보 구성
- `src/app/KaSectionDrawingStudio.*`
  - 좌측 레이어 창, 중앙 조판 보기, 우측 속성 창
  - GeoTIFF 추가 요청과 PDF 저장
- `src/app/MainWindow.*`
  - 단면도 아이콘과 탭 생명주기만 담당
- `tests/test_section_layout.cpp`
  - 10cm 눈금, 상대 거리, 자동 간격, 잘못된 입력, 조판 항목과 PDF 설정 검증

## 오류 처리

- 표시할 레이어가 없으면 단면도 생성을 막고 GeoTIFF 추가 안내를 표시한다.
- 유효하지 않거나 무한한 범위, 0 이하 눈금 간격, 지나치게 많은 눈금은 거부한다.
- 눈금은 축마다 최대 500개로 제한해 조판 정지를 방지한다.
- PDF 실패 시 파일 경로와 QGIS 오류 코드를 사용자에게 표시한다.

## 완료 기준

- 메인 아이콘에서 별도 `단면도` 탭이 열린다.
- 좌측 레이어 창, 중앙 가로 용지, 우측 단면 속성 창이 동시에 보인다.
- 좌측 0.10m 표고 눈금과 하단 거리 눈금이 실제 단면 범위에 맞는다.
- 붉은 점선 0.20mm 기준선과 축척·좌표계·표제 정보가 생성된다.
- PDF에서 사진은 래스터이고 눈금·문자·선은 벡터로 유지된다.
- Release 빌드, 관련 단위 테스트, 전체 ctest, 시작 스모크가 통과한다.

## 범위 밖

- 기존 `section_line`을 `LineStringZ`로 마이그레이션하는 작업
- 사진측량 3D 모델에서 새 표고를 계산하거나 단면 GeoTIFF를 생성하는 작업
- GeoTIFF에 없는 벽면 수직 깊이를 복원하는 작업
